This repository contains the Julia files used to prepare the data as well as the data used for the paper "Empirical bounds for commuting dilations of free unitaries and the universal dilation constant" by Malte Gerhold, Marcel Scherer and Orr Moshe Shalit, published in the The Journal of Experimental Mathematics, 2026. 

THe paper can be found here: https://arxiv.org/abs/2510.12540

The Julia files are calculations.jl and functions.jl, they can be run to conduct similar experiments and produce similar data.
